## NFL projections

```
cd nfl
python nfl_prod_projections.py
```

- Year and week are detected automatically; set `PREDICT_YEAR` / `PREDICT_WEEK` in the `__main__` block to override.
- All data comes from the free [nflverse](https://github.com/nflverse) game-by-game files (downloaded on each run and cached in `nfl/data_cache/`; the latest season is refreshed every run), so nothing is scraped from Pro-Football-Reference any more.
- **The model** (`nfl_model.py`) rates every team before each game on six stats, offense and defense separately: net yards, turnovers, **first downs**, points and plays (the full model also tests EPA per play, which added nothing). Ratings are recency-weighted averages that are adjusted for the strength of the opponents faced, shrunk toward the league average early in the season and carried partly across seasons. A ridge regression combines both teams' ratings with a margin-based Elo rating, rest days, neutral site and quarterback quality and injury status to project the home margin. It trains on the last 12 seasons of games played before the week being projected, and the projections average **10,000 bootstrap fits** (`BOOTSTRAP_RUNS` in `nfl_prod_projections.py`): the regression is refitted 10,000 times, each time on a resample of the training games drawn with replacement, and the projection (Mean) is the average of those fits while StdDev is how much they disagree. More runs make the average and StdDev steadier (they settle within a few hundred runs: 200 and 1,000 runs differ by about 0.05 points); they do not change the model or the picks, which come from the correction model below. 10,000 runs take about 70 seconds.
- **Progress logging:** a run is logged in 8 numbered steps, each with its time, and the bootstrap reports every 10% with the time elapsed and an estimate of the time left; a full run takes about 2 minutes. The log goes to the console and to `C:/Users/Bobby/nfl_predictions_<timestamp>.txt`.
- In a 2014-2026 walk-forward test this projects margins about 0.2 points better than the previous model (average miss 10.19 vs 10.40 points; the closing spread's is 9.94). First downs help only marginally on top of the other stats (removing them costs about 0.01 points). Against the closing spread it still picks winners at about 51%, so it is information to weigh and not a source of picks.
- Results are logged and written to `<year>_nfl_projections.xlsx` on the Desktop. Each run adds its week in week order, so a week run late is inserted after earlier weeks and before later ones. Every run refreshes the final margin for all games played so far. Notes are never touched.
- Blank spreads are filled in with DraftKings lines from Action Network's public scoreboard feed (home spread, negative = home favored). If DraftKings has no line for a game, the consensus line (then other books) is used and the run logs which book it took. Spreads already in the sheet are never replaced. A game that has already kicked off when its week is first written, whether under way or finished, gets the closing line (once a game starts the feed also carries live in-game lines, which are ignored), so a week run late is still written out in full. Action Network has DraftKings lines from 2024, consensus lines only for 2023, and nothing earlier, so those stay blank.
- **The workbook has three tabs** and opens on the first:
  - **This Week** is what to bet: the season scoreboard (pick record and win %, last week's picks, teaser-leg record and win %, average line versus the close), then **this week's picks**, each with its lean, historical win % and QB note and the model's reason under it, then the week's **teaser legs**, then every game of the week with the side the model leans to. It fits on one screen without scrolling sideways, and every cell points into the Season Log.
  - **Season Log** is the running record, one row per game: Week, Away, Home, Home Spread, **Pick** (e.g. "Bills +3"), **Teaser Leg** (e.g. "Saints +8.5"), Lean to Underdog, Hist. Win %, Final Margin, Pick Result, Teaser Result, Line vs Close, QB Note, Notes and **Why the Model Leans**. The yellow columns (Home Spread, Final Margin, Notes) are the ones to edit by hand. The detail columns (fair line, model side, covering team, closing spread, raw model correction, year) are grouped and collapsed at the right; click the + above them to show them. Week, Away and Home stay frozen while you scroll, and the header row has filters.
  - **Model Info** holds the editable settings (minimum lean to the underdog, first and last pick week; the formulas follow a change at once and the next run keeps it), the backtest tables and a short guide to reading the workbook.
- The workbook is rewritten every run and read back by column header, so a workbook in an older layout is converted in place (the old file is kept once as `<year>_nfl_projections_before_new_layout.xlsx`). The run saves to a temporary file and swaps it in, so close the workbook in Excel before running or the save fails (the run logs it).
- Pick Result, Teaser Result and Model Side Result are shaded light green for a win and light red for a loss, picks light blue, teaser legs light orange, and each week's games are boxed with a bold outline.
- The Fair Line (a detail column) is the spread moved by the model's correction (see the picks below), so the Model Side always agrees with the model. The stats-only projection above is still logged but had no edge against the spread (it picks winners at about 51%), so it no longer sets the sheet's fair line. If no spread is available when you run, the stats-only line is used until one is. Every run recomputes the fair line from each game's spread and correction, and earlier weeks already in the sheet that predate the signal get their corrections and reasons filled in (they use only pre-game data). The Model Side on a game that is not a Pick is not a bet.
- The Hist. Win % column shows how often the model's side covered at that size of lean toward the underdog, over every game from 1999 to date in weeks 5-16, each scored by a model that never saw it (break-even at -110 is 52.4%). The table behind it is on the Model Info tab, with the number of games behind each rate and the teaser-leg rates. It is recomputed every run (`nfl_signal.backtest_hit_rates`, `nfl_signal.teaser_leg_rates`); nothing in it is typed in.
- **Why did it pick that?** Every game carries the model's reason (`nfl_reasons.py`). The headline names the team the model leans to, by how much, and the themes behind it, strongest first, e.g. "Titans by 0.7: defense (worse), pace, pass defense (worse); against: takeaways". Under each pick on This Week, one line per theme gives its points of lean and its main rating with both teams' numbers, e.g. "+0.40 defense, mainly success rate in competitive game states allowed: TEN 46%, HOU 39% (TEN worse)", and a last line says whether those effects have been steady over the training years or have flipped. "(worse)" on a theme that helps a team means the team is worse there and the model still likes it, because the line has historically overrated that gap; that is how the model ends up on bad teams like the 2026 Titans. The Season Log shows the headline; select the cell to read the rest. For the full breakdown, `python nfl_explain.py TEN` (any team code; add a season and week for another game) lists the dozen largest ratings, each marked steady or flipping.
- **Picks.** A game is a *Pick* when it is a regular-season week 5-16 (the "First pick week" and "Last pick week" settings) and the second model (`nfl_signal.py`, a ridge fit on play-by-play and box-score team ratings) thinks the underdog covers, by more than the "Minimum lean to underdog" setting (default 0). That is about 4-5 picks a week. Those underdogs covered **53.7% on 1999-2005, 55.4% on 2006-2017 and 55.0% on 2018-2026** (1999-2005 was never used by any research step, so it is the clean test); about +7% ROI at the real closing odds. Expect about 55%, not 60%: the model's information is real and the same in every era, but it is only strong enough for about 55% (60% would need a signal roughly twice as informative), and with about 60 picks a season about one season in three will still lose money. A narrower key-number rule that looked like 65.8% on 2006-2026 went 53-50 (51.5%) on the untouched seasons and was dropped; see `nfl/README.md` and `python nfl_research_validate.py`.
- **Teaser legs.** The *Teaser Leg* column flags the published Wong teaser legs: underdogs of +1.5/+2.5 teased 6 points to +7.5/+8.5, and favorites of -7.5/-8.5 teased to -1.5/-2.5 (pair two of them in one 2-team, 6-point teaser). Legs won about 75% in every era since 1999, weeks 5-16 (favorite legs 71% since 2018); a 2-team teaser needs 72.4% per leg at -110 and 73.9% at -120, and wins about 55-58% as one bet. Check your book's teaser price: at -130 or worse the edge is gone.
- The weekly run warns when the sheet's spread for an unplayed game differs from the current DraftKings line; a pick or teaser leg holds only at the line you can actually bet, and the backtests bet the closing line.
- Once a game is played the sheet fills in its closing spread and the **Line vs Close** (how many more points the pick got than the closing line; positive means you beat the close), and the scoreboard at the top of This Week keeps the pick record and win %, last week's picks, the teaser-leg record and win %, and the picks' average line value, so you can see the season's hit rate at a glance.
- Each run also appends the current lines and public betting splits to `nfl/data_cache/line_log.csv` with a timestamp, so there will eventually be real data on how far lines move between when you bet and the close (the public history only has stale openers and the close).

- The QB Note column lists games where a team's previous starting quarterback is on this week's injury report (Out, Doubtful or Questionable) and games where the schedule expects a different starter than last week. It comes from the free nflverse injury reports, is refreshed on every run for games not yet played, and is kept as-is once a game has been played. It is information to read, not a signal the projections use: in backtesting it did not predict covers (see below).

## Research: can any model beat the closing spread?

`nfl_research_signal.py` is the evidence for the underdog signal (information test, underdog versus favorite picks against the no-model baseline, confidence, thresholds, a nested walk-forward that picks its own settings each season, and a placebo test). It runs on `nfl_lab.py`, a research framework with ratings on 37 box-score and play-by-play stats back to 1999 (`nfl_pbp_features.py` builds the play-by-play aggregates), market prices, weather and context features, and walk-forward scoring tools that report a discovery period (through 2017) and a holdout period separately. `nfl_lab_extra.py` (cover history, travel) and `nfl_market_moves.py` (opening lines and betting splits) hold the other angles that were tested and found to add nothing usable.

`nfl_research_model.py` compares the margin model with the previous production model, each stat set (yards and turnovers, plus first downs, points, plays, EPA), Elo and quarterback features, with paired significance tests. `nfl_prod_backtest.py` replays seasons week by week with the production model.

`nfl_research_ats.py` runs the same kind of walk-forward test against closing spreads for 2012-2026 (about 3,600 games) with other model types, including gradient boosting, and reports ATS win rates by season, edge size and spread size (including spreads of 4 and up).

`nfl_research_injuries.py` layers pre-game injury features from `nfl_injury_features.py` (quarterback status from the official reports, quarterback quality, and counts of players Out or Doubtful by position group) onto that test and looks directly at games where a starting quarterback is out.

`nfl_sim.py` is a Monte Carlo game simulator: each team gets a number of scoring drives, touchdowns and field goals are drawn from binomials with era-based extra-point and two-point rates, and expected points are centered on the closing line plus the signal's correction. Simulated margins are reweighted so the key numbers (3, 7, ties, pushes) match the last 12 seasons of real results. `nfl_research_sim.py` uses it to test selecting bets by simulated expected value (it did not beat the simple correction-size rule), moneyline bets (no edge), Kelly staking, and a season-level bootstrap, Bayesian posterior and bankroll simulation of the signal's uncertainty (true win rate roughly 52-55%, so losing seasons are common). The simulator is research-only and does not feed the spreadsheet.

`nfl_research_features.py` asks which stats carry information the spread does not, scored on weeks 5-16 with stats chosen on 2006-2017 and confirmed on 2018 onward: your gut set (yards, first downs, turnovers) and the whole box-score family carry none (the market already prices them), no single stat clears chance on its own (the best of 37 is t of about 2.4), and the whole edge sits in the 31 play-by-play stats taken together. A forward selection finds a 4-stat set (drives, special-teams EPA, rushing success rate, interception rate) that correlates better with cover margin on the holdout (r 0.11 versus 0.065), but it picks worse (underdog top 3 a week 52-55% versus 57.6% for the full model), so a smaller model is not a better betting model. An underdog-frame model and a consensus of several models land in the same 56-58% band; requiring two models to agree is the best of them (about 57-58% on 3-5 picks a week in both periods), which is within noise of the current signal after the number of variations tried.

`nfl_research_validate.py` is the honest check of all of the above (October 2026): it scores the 1999-2005 seasons, which no research step had used, with a model fitted on 2006-2019. The key-number rule failed there (51.5%), the quarterback-change filter helped only there, and the correction's information turned out stable in every era (correlation with the cover margin 0.06-0.08), which supports about 55% and not 60%. The 4-stat model above passed a pre-registered test on information (0.10-0.11 versus 0.06-0.08 in the two eras its selection never saw) but its picks also land at about 54-55%. It also tests the published Wong teaser rule (legs about 75% in every era). See `nfl/README.md` for the full write-up.

`nfl_research_data.py` tests data the model does not use (October 2026), each against a rule fixed before running: 15 seasons of opening and closing lines from Sportsbook Reviews Online's free archive (`nfl_market_history.py` downloads and parses them), betting at the open instead of the close, a rating of each game's actual starting quarterback, record and luck, pass rush and coverage (QB hits and passes defended), team popularity (primetime games), and retuned rating memory. None added information beyond the closing line, and none produced an edge on favorites: public information is already in the line.
